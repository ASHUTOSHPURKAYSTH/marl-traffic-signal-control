# Data

Raw datasets are not committed to this repository.

## CityFlow Open Dataset
1. Visit https://traffic-signal-control.github.io/dataset.html
2. Download Hangzhou (4x4), New York (16x3), and Jinan (3x4)
3. Place files as:
```
data/
  hangzhou/  roadnet.json, flow.json
  newyork/   roadnet.json, flow.json
  jinan/     roadnet.json, flow.json
```
